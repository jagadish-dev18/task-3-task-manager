# Task 3 — JavaScript Logic & State Management

A browser-based task manager built as a practice rebuild of the dashboard brief.

## Features
- Add a new task (Create)
- Show saved tasks (Read)
- Edit a task title (Update)
- Delete a task (Delete)
- Mark tasks complete or active
- Filter All, Active and Completed tasks
- Save task data in browser `localStorage`

## Run locally
Open `index.html` in a modern browser. No server or packages are needed.

## Data note
Tasks are stored only in the current browser profile on this device. Clearing browser site data can remove them. There is no user account or remote database.

## Suggested walkthrough
Add two tasks, complete one, filter the list, edit the other and delete it. Then refresh the page to see localStorage in action.
